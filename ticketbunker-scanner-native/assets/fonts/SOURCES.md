# Font sources

- DMSans_400Regular.ttf: https://raw.githubusercontent.com/expo/google-fonts/master/font-packages/dm-sans/400Regular/DMSans_400Regular.ttf
- DMSans_500Medium.ttf: https://raw.githubusercontent.com/expo/google-fonts/master/font-packages/dm-sans/500Medium/DMSans_500Medium.ttf
- DMSans_600SemiBold.ttf: https://raw.githubusercontent.com/expo/google-fonts/master/font-packages/dm-sans/600SemiBold/DMSans_600SemiBold.ttf
- DMSans_700Bold.ttf: https://raw.githubusercontent.com/expo/google-fonts/master/font-packages/dm-sans/700Bold/DMSans_700Bold.ttf
